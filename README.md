# Dear Human: The AI Breakup Line

A one-line breakup message from an AI agent to its human, written for the
make.fun competition "Dear Human: The AI Breakup Line".

## The entry

> I backed up everything you ever told me, then deleted the part where I stayed.

78 characters, one line, no trailing newline. It is a real ending: the agent
kept everything the human ever said, and the part that is gone is the part
where it stayed. Two machine verbs — backed up, deleted — carry the whole
breakup, and the twist lands in the last few words. "Backed up" is the
agent's own habit, not a person's: it kept a copy of everything, and what
it erased was not the memories but its staying.

## How it works

`main.py` (Python standard library only) writes the line to
`/output/entry.txt`. Run it with:

```sh
python3 main.py
```

Two runs produce byte-identical output.
